**[Chrono Rig 2D]** is a high-performance, lightweight 2D skeletal animation and bone rigging tool built for game developers, digital artists, and animators. Inspired by industry standards like Spine and DragonBones, it brings modern mesh deformation and inverse kinematics to your 2D workflow—powered by a sleek, desktop-first architecture.

---

## ✨ Features

*   🔗 **Intuitive Bone Rigging:** Create hierarchical skeletal structures with parent-child bone relationships, custom pivot points, and precise constraint handling.
*   🗺️ **Mesh Deformation:** Flex, bend, and warp your 2D artwork organically using weighted vertices and meshes.
*   ⏱️ **Timeline & Keyframing:** Smooth interpolation, ease curves, and multi-track animation timelines to bring your sprites to life.
*   ⚡ **Lightning Fast:** Built on Electron and React, offering a responsive native desktop experience with hardware-accelerated rendering.
*   📦 **Lightweight Exports:** Export compact animation data and sprite atlases ready to drop straight into your favorite game engines (Godot, Unity, Phaser, etc.).
